Entropi Coaching · subscription · local launch candidate

Lokalt klart. Ikke åbent for rigtige brugere endnu.

Denne side er den eneste frigivelsescheckliste for aftenens kandidat. Den skelner mellem det, der kan bevises lokalt, og den ene eksterne port, der stadig mangler. En lokal grøn status er ikke en bruger-lancering.

Grønne gates

Skal være grønne før lokal review eller shadow-forberedelse

✓
Build og statiske entrypoints

npm run build:subscription-pilot er grøn. Alle review-flader bygges lokalt, og direkte file://-åbning viderestiller til den byggede kopi i stedet for en tom JSX-side.

✓
Produktrejse og programlogik

npm run test:subscription og npm run verify:subscription-pilot-smoke er grønne: onboarding, synligt uge-2-valg, lokalt snapshot og feedbackartefakt følger den lokale kontrakt.

✓
Produktseparation

npm run verify:subscription-separation er grøn. Subscription-sporet falder ikke tilbage til 1:1-klienten, data eller PWA-flade.

✓
Mobil og feedback-review

Gennemgå kunderejsen, mobilchecklisten og feedbackfladen fra den byggede lokale pakke. P0 er: blokeret vej, forkert program, skjult belastningsændring eller blandede lokale testerdata.

Én ekstern blocker

Verificeret shadow-binding

!
Ikke klar: binding til maxhsefxbrvsgolscqwh.

Der er ingen verificeret, projektafgrænset operator eller de tre lokale VITE_SUB_SUPABASE_*-værdier. Derfor er der ikke kørt login, invitation, migration, databaseadfærd eller rigtig brugerrejse. Denne port må kun åbnes af Sol med dokumenteret shadow-adgang.

Beslutning i aften

Præcis status

Ja: en lokal, manuel review af appens demo- og QA-flader kan gennemføres i aften.

Nej: en rigtig bruger kan ikke lanceres i aften uden den verificerede shadow-binding og dens efterfølgende sikkerheds- og adfærdsgates.
