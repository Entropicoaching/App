# REL1030

Tilvalg: aabn appens normale URL med ?rel1030=1, eller tilfoej &rel1030=1 hvis der allerede er parametre. Marc og de udvalgte atleter bruger hver deres link og deres normale konto. Tilvalget gaelder kun den aktuelle URL, er ikke adgangskontrol og gemmes ikke. Fjern parameteren og genindlaes for at vende tilbage. Pracis en vaerdi paa 1 accepteres. Dubletter aktiverer ikke pakken. Et individuelt flag kan stadig aktivere sin egen funktion.

Lukket liste:

| Funktion | Eksisterende flag eller indgang |
| --- | --- |
| APP-MOB1 fokus og genvej | mobilitetFokus |
| APP-MOB2 oevelsesbibliotek fra fokusvisningen | mobilitetFokus |
| APP-MOB3 kort rutine foer dagens pas | mobilitetFoerPas |
| APP-MOB4 lokal registrering af hvad der hjalp, og lokal coachvisning | mobilitetHjalp |
| Samlet analyseprototype | analyseSamlet=1 |
| Sammenligningsprototype | analyseSammenlign=1 |
| Coachoprydning | coachRyd=1 |
| Coachens uge | coachUge=1 |
| Afspil coachens tidsmarkeringer | localStorage vc-epik2-playback=1 |

De tre mobilitetsprops bliver true i App, inklusive coachens atletvisning. Coach faar mobilitetHjalp. De fire eksisterende querylaesere og tidsmarkeringslaeseren accepterer ogsaa rel1030. Individuelle props og flag virker stadig alene. Alle defaultkonstanter er fortsat false. rel1030 skriver ingen flag til storage og aendrer ingen URL.

Rettelser som allerede er flettet i b8dd5b94 forbliver i basen. Pakken aktiverer ingen andre tilvalg, eksempelvis enkelPrototype, forenklinger, fremgangFokus, naesteTraening, staevnedagFokus, blokFremgang, kostPerAtlet, coachMorning, coachPlanCopy, appE2E2, appRel3 eller appData2. Analysevisningerne er fortsat syntetiske prototyper. Tidsmarkeringer kraever stadig lokal markeringsfil og matchende klip. Ingen backendformat eller adgangsregel aendres.

Operatoerens tjekliste efter integration:

- [ ] Uden rel1030: samme visning og individuelle flag som basen.
- [ ] Med rel1030: mobilitetsfokus, bibliotek og lokal hjaelp virker for valgt atlet.
- [ ] Dagens pas: rutinen vises kun foer et egnet pas; eksisterende logning bevares.
- [ ] En dag uden traening: intet falsk pas eller rutine; mobilitetsgenvejen kan stadig bruges.
- [ ] Program, naeste uge: skift uge, kontroller plan og vend tilbage til dagens pas.
- [ ] Coach: ugeoversigt, oprydning, atletvisning og tilbage til coach.
- [ ] Analyse: samlet og sammenlign, fortsat med syntetiske data.
- [ ] Beskeder: aabn tidsmarkeringer, vaelg gyldig lokal fil og klip; kontroller afgraensning til atlet og analyse.
- [ ] Fjern rel1030 og genindlaes: ingen vedvarende aktivering.
- [ ] Koer fuld suite i LF-udtjekning og build som operatoertrin.
